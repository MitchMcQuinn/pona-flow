# Public documentation

Guides in this folder are the public contract for a pona flow instance: how an external system, script, or agent integrates with the HTTP API.

Operator and contributor notes live in [`Docs/`](../Docs/). Add a new public guide here when it describes behavior an integrator can rely on without reading the source.

| Guide | What it covers |
| --- | --- |
| [API](api.md) | Authentication, running sequences, the runtime MCP gateway, inbound event hooks, and the HTTP endpoints the authoring MCP calls. |
