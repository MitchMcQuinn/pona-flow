Cloud setup wizard

You create accounts on Neo4j Aura and Fly.io (and optionally Clerk). This page never uploads your secrets — it only builds the commands for you to paste into a terminal.

    Before you start

    • A computer with a terminal (macOS, Linux, or WSL).
    • Accounts you can create for free: Neo4j Aura Free and Fly.io.
    • Optional: a Clerk app if you want their sign-in UI instead of built-in email/password.

    Prefer local Docker only? Use the Community / Docker guide instead.

    1. Neo4j Aura

    1. Open console.neo4j.io and create an Aura Free instance.
    2. Copy the connection URI, username, and password (the password is shown once).

    2. Fly.io app

    1. Install the CLI: curl -L https://fly.io/install.sh | sh (or brew install flyctl).
    2. Sign in: fly auth login.
    3. Pick an app name (letters, numbers, hyphens). It becomes https://<name>.fly.dev.

    3. Sign-in

    Built-in email/password is the default (no third party). Clerk is optional.

    From the Clerk dashboard → API Keys. The first person to sign in becomes instance admin.

    After deploy, the first account is created with the setup command (you stay admin).
