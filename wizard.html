Self-hosted edition

Cloud setup in the terminal

You create accounts on Neo4j Aura and Fly.io (and optionally Clerk). Then one command prompts for those values and deploys ghcr.io/mitchmcquinn/pona-flow:main. Secrets stay on your machine.

Before you start

  • A computer with a terminal (macOS, Linux, or WSL).
  • A free Neo4j Aura instance — copy the neo4j+s:// URI and the password shown once.
  • A Fly.io account.
  • Optional: a Fly Access Token so the instance can update itself from the gear menu later. Or run fly tokens create deploy --name pona-flow-updates.
  • Optional: a Clerk app if you want their sign-in UI instead of built-in email/password.

Install flyctl and sign in

brew install flyctl
fly auth login

Linux: curl -L https://fly.io/install.sh | sh

Run the installer

Download, review, then run. Do not paste a raw #!/… script into zsh (the ! triggers “event not found”). 

curl -fsSL https://raw.githubusercontent.com/MitchMcQuinn/pona-flow/main/scripts/fly-setup.sh -o pona-flow-fly-setup.sh
# optional: open the file and read it
bash pona-flow-fly-setup.sh

The script asks for Aura, a Fly app name, region, sign-in details, and (optionally) the deploy token. It creates the app, sets secrets, and pulls the latest main image.

When it finishes, open https://<your-app>.fly.dev and sign in.

Updates later

Instance administrators open the gear menu in the app. If this instance is behind main, you will see the commit messages since your last deploy and an Update to latest main button (when a Fly token is saved).

Prefer local Docker only? Use the Community / Docker guide.
