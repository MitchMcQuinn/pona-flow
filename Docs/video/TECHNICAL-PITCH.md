# Technical pitch — video script

**Runtime:** 2:57
**Cut:** [technical-pitch.mp4](technical-pitch.mp4)
**Pace:** unhurried, about 150 words a minute. Each picture stays up long enough to read after the line ends.

This is the engineer-facing cut. It names schema, instance, and step, and it walks a branch and a pause. The agency cut stays on the pain and where pona flow sits: [AGENCY-PITCH.md](AGENCY-PITCH.md).

One Monday. Schema, instance, and step each get their own picture, using the contractor Maya is clearing. The words on the pictures are the words in the narration.

The recording uses these lines in this order. Read them again in your own voice if you want a human track; keep the pictures where they are.

## 0:00 — Open

**Picture:** title card. pona flow. The Monday checklist. Routine work, when the context is not.

Every Monday, Maya clears a new contractor before payroll. The checklist never changes. Find the person. Check which rule applies. Call a screening service. Ask legal when the contract is large. Wait if the tax form has not arrived. Then write the result back, so finance can pay them. The steps are routine. The context around them is not.

## 0:24 — Six rooms, then one

**Picture:** [wiki, spreadsheet, automation, search, chat, and a prompt, then meaning, records, and work](../visuals/01-split-stack-vs-one-model.png)

Last quarter, that morning lived in six rooms. A wiki. A spreadsheet. An automation. A search box. A chat thread. A prompt. Each held one piece of the Monday. pona flow puts that morning in one room: what things mean, the records themselves, and the work.

## 0:43 — Schema

**Picture:** [a contractor is both a person and a vendor; high-value requires legal review](../visuals/07-schema.png)

Schema is the rulebook. A contractor is both a person and a vendor. A high-value agreement requires legal review. The rule lives on the type, so changing it once changes every record of that type.

## 1:00 — Instance

**Picture:** [this person links to this company, which links to this agreement](../visuals/08-instance.png)

Instance is the chart. This person bills through this company. This company holds this agreement. Ask who is behind the invoice, and you walk those links.

## 1:15 — Step

**Picture:** [find the person, check the rule, call screening, ask legal, wait for the form](../visuals/09-step.png)

Step is the checklist you already heard. Find the person. Check the rule. Call screening. Ask legal. Wait for the form. A sequence is the name of the first step. The run walks from there.

## 1:32 — Three lanes

**Picture:** [schema, instance, and step, each linking only to itself](../visuals/10-lanes-recap.png)

Three lanes, one Monday. Rules link to rules. Records link to records. Steps link to steps. A lane links only to itself.

## 1:47 — The walk

**Picture:** [high-value asks legal; a missing form pauses the same run](../visuals/03-execution-walk.png)

A branch and a pause are different. High-value agreements go to legal. The others continue. You change that by editing the arrow. A pause is a fact that is not here yet. The form. A signature. A figure that arrives at four. The run stops, marks itself pending, and hands back a state id. Bring the missing piece back, and the same Monday continues.

## 2:10 — Three doors

**Picture:** [dashboard, webhook, and a chat tool opening one checklist](../visuals/04-one-run-three-doors.png)

Three doors open that same checklist. Maya starts it from the dashboard. Payroll sends a webhook. A chat tool calls it the way it calls any other tool. If the form is missing, every door hears the same pause.

## 2:26 — The trace

**Picture:** [this agreement, high-value, legal review](../visuals/11-the-trace.png)

When someone asks why, the path is the answer. We asked legal because this agreement is high-value, and high-value requires legal.

## 2:41 — Close

**Picture:** end card. The checklist repeats. The context does not.

That same Monday shows up wherever a repeated task has to gather dependencies, stakeholders, services, and a fact that arrives late. The checklist repeats. The context does not.
