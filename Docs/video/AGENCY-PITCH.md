# Agency pitch — video script

**Runtime:** 1:57
**Cut:** [agency-pitch.mp4](agency-pitch.mp4)
**Audience:** an agency owner who has tried to let an assistant act, and watched it finish on the wrong account
**Voice on this cut:** the Bella profile in Voicebox (Kokoro)

The assistant is the subject. Scattered context is what makes it confident and wrong. pona flow is where that assistant acts, on one account, and where it stops when a required piece is missing. The technical cut is [TECHNICAL-PITCH.md](TECHNICAL-PITCH.md).

## 0:00 — Open

**Picture:** title card. pona flow. For agencies. The assistant, and the account it must use.

An agency lives on routines. Kick off a client. Route a revision. Get an approval. Publish the work. You have tried letting an assistant take those on. The steps repeat. The assistant does not.

## 0:14 — The context is scattered

**Picture:** [client list, thread, brand doc, files, project tool, and a person's head](../visuals/agency-01-pain.png)

The client is in one tool. The approver is in a thread. The brand rule is in a doc. The file is in another service. And the account lead is carrying the rest.

## 0:29 — It finished anyway

**Picture:** [a message addressed to Client A's approver, priced at Client B's rate, in Client C's tone](../visuals/agency-04-wrong-send.png)

Ask the assistant to send the update, and it does not stop. It finishes. Client A's approver. Client B's rate. Client C's tone. One message, because those pieces were nearby.

## 0:47 — What the assistant may do

**Picture:** [dashboard, chatbot, and service start one account, then ask this approver, follow this brand rule, or wait for this file](../visuals/agency-05-allowed.png)

pona flow is where that assistant acts. The dashboard, the chatbot, and your other services start the same routine. The routine reads this account. It may ask this approver. It may follow this brand rule. If the file is missing, it waits.

## 1:11 — Campaign approval

**Picture:** [a campaign approval tied to the client, the approver, the brand rule, and a file that arrives later](../visuals/agency-03-routine.png)

Take a campaign approval. The assistant asks that account's approver, and it follows that account's brand rule. The file is not here yet, so the same piece of work holds. It does not invent the file. It does not borrow the next client's rate.

## 1:32 — Name it once

**Picture:** title card. Name it once. The producer and the assistant share it.

Someone on the team names the client, the approver, and the rule once. After that, the producer and the assistant use the same ones. Monday and Thursday do not diverge.

## 1:48 — Close

**Picture:** end card. It uses the account. It stops when something required is missing.

The assistant uses the account's context. And it stops when something required is missing.
